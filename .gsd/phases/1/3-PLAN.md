# Plan 1.3: Tiled Village Map, Generated Assets & World State Loader

## Objective

  <action>
    Write `scripts/generate_village_map.py` using Python 3.12 standard library (`zlib`, `struct`, `json`, `pathlib`, `collections.deque`) and run it to emit `tileset.png`, `sprites.png`, and `map.json`.

    Steps:
    1. Implement a minimal RGBA PNG encoder in `scripts/generate_village_map.py` using `zlib.compress` + `struct.pack` (PNG header, `IHDR`, `IDAT`, `IEND` with `zlib.crc32`) — no external image library needed.
    2. Build `tileset.png` as a `256 x 128` RGBA image (`8 columns x 4 rows` of `32x32` tiles, 32 tiles total, GIDs `1..32`):
       - Include crisp shaded pixel tiles: grass (GID 1), flower grass (GID 2), cobble road (GID 3), town plaza stone (GID 4), wood floor (GID 5), cafe/tile floor (GID 6), water pond (GID 7), tree/hedge (GID 8), stone wall (GID 9), timber wall (GID 10), red roof (GID 11), blue roof (GID 12), green roof (GID 13), amber roof (GID 14), doorway threshold (GID 15), park bench (GID 16), market stall (GID 17), cafe counter (GID 18), bookshelf (GID 19), collision marker overlay tile (GID 20 — translucent red crosshatch).
    3. Build `sprites.png` as a `128 x 128` RGBA image (`4 columns x 4 rows` of `32x32` frames = 16 frames total: rows 0..3 correspond to 4 distinct villagers Maya/teal, Liam/amber, Elena/violet, Noah/emerald; columns 0..3 give idle + walk poses with distinct head, hair, torso, legs, and drop shadow).
    4. Construct `map.json` (`40` cols x `30` rows, `tilewidth: 32`, `tileheight: 32`, `infinite: false`, `orientation: "orthogonal"`, `version: "1.10"`, `tilesets: [{"firstgid": 1, "name": "village_tiles", "image": "tileset.png", "imagewidth": 256, "imageheight": 128, "tilewidth": 32, "tileheight": 32, "tilecount": 32, "columns": 8, "margin": 0, "spacing": 0}]`) with 4 layers:
       - `"ground"` (`type: "tilelayer"`): grass base, 2-tile-wide cobblestone road grid connecting all buildings and central `"Town Square"` plaza, `"Park"` with pond and flower lawn, and at least `3x3` walkable interior floors for `"Cafe"`, `"Market"`, `"Bakery"`, `"Library"`, `"Home_Maya"`, `"Home_Liam"`, `"Home_Elena"`, `"Home_Noah"`.
       - `"structures"` (`type: "tilelayer"`): roofs, exterior walls (leaving 2-tile-wide doorways onto roads!), interior counters/stalls/shelves/benches, perimeter trees.
       - `"collision"` (`type: "tilelayer"`): GID `0` on every walkable road, plaza, park path, doorway, and open building interior; GID `20` (non-zero = impassable) on every wall, roof, pond tile, tree, and counter/furniture tile.
       - `"locations"` (`type: "objectgroup"`): 10 named `object` entries (`Cafe`, `Park`, `Market`, `Town Square`, `Bakery`, `Library`, `Home_Maya`, `Home_Liam`, `Home_Elena`, `Home_Noah`), each with `id`, `name`, `type: category`, pixel `x`, `y`, `width`, `height`, and Tiled `properties: [{"name": "anchor_x", "type": "int", "value": ...}, {"name": "anchor_y", "type": "int", "value": ...}, {"name": "category", "type": "string", "value": ...}]`.
    5. Resolve output directory via `Path(__file__).resolve().parents[1] / "frontend" / "public" / "assets"` so the script works from any working directory, and assert via BFS from `Town Square`'s anchor that every named location's `(anchor_x, anchor_y)` has `collision == 0` AND is reachable from `Town Square`, failing loudly if not!
    6. Execute the script to produce `tileset.png`, `sprites.png`, and `map.json`.

    AVOID: Using `"compression": "zlib"` or `"infinite": true` in Tiled JSON, or naming the tileset differently from `"village_tiles"` (which breaks Phaser `addTilesetImage`).
    USE: Flat integer `"data"` arrays (`len == 1200`) and verify BFS reachability directly during generation.

<task type="auto">
  <name>Implement WorldMap loader and write offline world state unit tests</name>
  <files>
    backend/sim/world.py
    backend/tests/test_world.py
  </files>
  <action>
    Implement `backend/sim/world.py` to parse Tiled JSON maps and expose grid walkability, named location lookup, and non-overlapping tile helpers, plus comprehensive unit tests in `backend/tests/test_world.py`.

    Steps:
    1. Define `GridPos = tuple[int, int]` and Pydantic/dataclass `NamedLocation(name: str, category: str, anchor_x: int, anchor_y: int, x: int, y: int, width: int, height: int)` with property `anchor -> GridPos`.
    2. Implement `WorldMap`:
       - Class method `from_tiled_json(path: Path) -> WorldMap` reading `map.json`, validating `width`, `height`, `tilewidth`, presence of `"collision"` tilelayer (`len(data) == width * height`) and `"locations"` objectgroup.
       - Store `collision_grid: list[list[bool]]` where `True` = blocked (`gid != 0`) and `False` = walkable (`gid == 0`).
       - Parse `"locations"` objects, extracting `anchor_x`/`anchor_y` from custom Tiled `properties` (falling back to object center tile if omitted, and raising `ValueError` if an anchor is out of bounds or on a collision tile!).
       - Provide `in_bounds(x: int, y: int) -> bool`, `is_walkable(x: int, y: int) -> bool` (in bounds and not collision), `get_location(name: str) -> NamedLocation`, `list_locations() -> list[NamedLocation]`, `find_free_adjacent(x: int, y: int, occupied: set[GridPos], max_radius: int = 3) -> GridPos | None` (BFS outward over walkable tiles returning first walkable tile not in `occupied`), and `reachable_from(start: GridPos) -> set[GridPos]`.
    3. Write `backend/tests/test_world.py` testing:
       - Loading `get_settings().resolved_map_path()` succeeds (`40 x 30`, `tile_size == 32`).
       - All required locations exist (`Cafe`, `Park`, `Market`, `Town Square`, `Bakery`, `Library`, `Home_Maya`, `Home_Liam`, `Home_Elena`, `Home_Noah`).
       - Every named location anchor is walkable (`world.is_walkable(*loc.anchor) is True`) and has >= 1 walkable neighbor.
       - BFS from `Town Square` reaches 100% of named location anchors.
       - Collision tiles (e.g., perimeter tree/wall tiles) return `is_walkable(...) is False`, out-of-bounds `(-1, 0)` and `(40, 30)` return `False`.
       - `find_free_adjacent` skips occupied and blocked tiles and returns a valid nearby walkable tile.
       - Synthetic invalid map JSON (missing collision layer or blocked anchor) raises `ValueError`.

    AVOID: Mutating `collision_grid` for dynamic agent positions (keep static map geometry cleanly separated from dynamic agent `occupied` sets).
    USE: Pure read-only static collision lookup + dynamic `occupied: set[GridPos]` parameter for `find_free_adjacent`.
  </action>

  </verify>
